# 成长森林

依据根目录的系统详细设计 V1.1、轻量技术实现方案及视觉设计 V2 开发。当前为 **0.3.0 礼品兑换与离线试用版**。

## 运行

需要 Node.js 22.12+（已在 Node.js 24 环境构建）。

```sh
npm install
npm run assets
npm run dev
```

打开终端显示的本地地址。业务数据保存于该地址下的 IndexedDB；不同域名或端口的数据相互隔离。不要使用 file:// 直接打开。

```sh
npm test
npm run build
```

## 当前实现

- Vue 3、TypeScript、Vite、Hash 路由及 Dexie 本地数据库。
- 三入口、昵称年级建档、六位伙伴选择、真实 V2 素材的 WebP 接入。
- 探索创建与编辑独立任务，0—99 星、1—60 分钟校验，开始后锁奖励。
- 今日任务、已有任务改期、排序版本校验、完整/部分自查、心情备注。
- 正/倒计时、暂停恢复、5秒检查点、隐藏自动暂停、异常空档不补计。
- 数据库计时所有权和代次检查；其他页面活动时拒绝开始第二会话，暂停后可接续。
- 幂等事务奖励、完成日统计、天/周/月/全部范围、专注趋势与 CSV。
- JSON 全量备份、版本/结构/引用/流水校验、导入预览、备份确认与事务替换。
- 目标创建/编辑/暂停/恢复；计划支持每日、每周指定星期和单次，显示未来7天预览。
- 四方向模板可在保存前修改目标、标准、日期、频率、时长、星星，并原子创建本地副本。
- 计划滚动生成7天窗口，按计划与原发生日去重；改期保持原ID，不补发关闭期间的历史任务。
- 计划编辑按生效日保留规则历史；单任务奖励覆盖和已开始奖励不会被改写。
- 目标与计划暂停来源分开，恢复不误恢复学生自行暂停的安排。
- 目标/计划分别回顾确认，按唯一来源授予成就/勋章；开始过的任务需先处理结果。
- 六伙伴三阶段、首次完成绑定当天旅程、幂等日结、10/20/30阶段推进、60开心日成长之星。
- 伙伴切换保留进度；新旅程需主动确认，历史收藏保留。成长统计区分本期收获与当前状态。

## 礼品与离线使用

我的成长 → 礼品兑换，包含可兑换、兑换记录、奖品设置。支持本地图片压缩、礼品停用、兑换前版本校验、领取与取消退星。订单保留兑换时的名称、图片和价格；并发请求不会重复扣星或透支。记录沿用成长页日期范围，也可单独查看全部兑换。

正式构建包含 PWA 和全部本地素材预缓存。执行 `npm run build` 后用 `npm exec vite -- preview --host 127.0.0.1 --port 4173` 预览。首次联网打开，等待“离线资源已就绪”；以后可离线打开并操作本机记录。开发服务器不启用 Service Worker，线上部署需 HTTPS。浏览器清理站点数据仍会删除记录，请定期备份。

发现新版本后手动更新；有编辑、专注或其他打开页面时阻止更新。图片、订单和专注保存在本机，不提供跨设备自动同步。

旧版本没有保存历史陪伴归属，升级不推测过去日期的伙伴开心值；从升级后的首次完整完成开始绑定日期。已有任务与星星记录保留。

回顾目标目前要求先逐项回顾完成所有关联计划；不会静默替孩子完成计划并授奖。未开始的剩余任务在回顾计划时列出，须明确确认结束。

原素材和设计文件保持在工程外；`scripts/assets.mjs` 从 `../视觉设计-V2` 生成运行图片及体积清单。页面稿没有作为整页图片使用。
